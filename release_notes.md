## What's New in v1.9.0

### 3 New Gameplay Features
- **Smooth Lane Switching**: Visual lean/tilt animation when switching lanes for a fluid arcade feel
- **Dynamic Day/Night Cycle**: The jungle transitions through dawn, noon, dusk, and moonlit night as you run further - 4000m cycle
- **Zombie Proximity Music Fade**: Background music volume drops when the zombie guardian closes in, building tension

### Changes
- Removed Volcanic Inferno, Frostbite Citadel, and Endless Voyage maps - Jungle Canopy only
- Updated spinning blade obstacle with textured PBR model
- All 8 heroes remain fully unlocked
- Locked 60 FPS on Android

### Download
- **APK Size**: ~132 MB
- **Min Android**: 8.0 (Oreo)
- **Architecture**: ARM64 + ARMv7 (IL2CPP)
